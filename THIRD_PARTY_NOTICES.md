# Third-party components and licences

The original KPI Bridge code is released under the MIT licence (see `LICENSE`). It uses the following components,
unmodified, whose licences are compatible with this distribution. Inventory generated with
`python scripts/check_licenses.py --markdown` (Python) and `npm ls --omit=dev` (frontend) on 2026-10-11; CI
rejects any AGPL/GPL-3/SSPL licence among the runtime dependencies.
